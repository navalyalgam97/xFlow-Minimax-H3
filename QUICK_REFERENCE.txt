SETUP (5 STEPS)
─────────────────────────────────────────────────────────────────────────
1. mkdir -p ComfyUI/custom_nodes/minimax-h3-video/{workflows,web}
2. cp minimax_h3_video_nodes.py → nodes.py
3. cp config.json
4. cp MinimaxH3Video.jsx → web/minimax_h3_video.js
5. cp Minimax H3 workflows → workflows/

VALIDATE
─────────────────────────────────────────────────────────────────────────
python3 -m json.tool config.json > /dev/null      ← Check JSON
python3 -m py_compile nodes.py                    ← Check Python
grep '"type"' text_to_video_workflow.json         ← Check nodes

TESTING
─────────────────────────────────────────────────────────────────────────
1. Start ComfyUI: python main.py
2. Add node: Right-click canvas → Add Node → Minimax H3 → One-Node Video
3. Test mode: Select "Text to Video"
4. Enter prompt: "A serene mountain landscape"
5. Click GENERATE VIDEO
6. Check logs for errors

API ENDPOINTS
─────────────────────────────────────────────────────────────────────────
GET  /minimax_h3/config                      ← Returns UI config
GET  /minimax_h3/workflow_text_to_video      ← Returns T2V workflow
GET  /minimax_h3/workflow_image_to_video     ← Returns I2V workflow
GET  /minimax_h3/workflow_reference_to_video ← Returns R2V workflow
POST /minimax_h3/set_output                  ← Store generation result
POST /minimax_h3/add_favorite                ← Add to favorites
POST /minimax_h3/remove_favorite             ← Remove from favorites

NODE INPUT TYPES
─────────────────────────────────────────────────────────────────────────
mode: "text_to_video" | "image_to_video" | "reference_to_video"
duration: INT (1-30 seconds)
fps: "24" | "30"
motion_strength: FLOAT (0.0-1.0)
guidance_scale: FLOAT (1.0-20.0)
prompt: STRING (optional, required for T2V)
image: IMAGE (optional, required for I2V)
reference_image: IMAGE (optional, required for R2V)
audio_file: AUDIO (optional, recommended for R2V)

NODE OUTPUT
─────────────────────────────────────────────────────────────────────────
VIDEO (tuple containing video tensor + metadata)
Stored as: outputs/MinimaxH3/video_<timestamp>.mp4
Metadata: outputs/MinimaxH3/metadata/video_<timestamp>.json

CUSTOMIZATION TIPS
─────────────────────────────────────────────────────────────────────────
• Add templates: Edit config.json "text_to_video_templates" array
• Change colors: Update config.json "colors" object
• Add modes: Extend SUPPORTED_MODES in nodes.py
• Modify UI: Edit MinimaxH3Video.jsx React component
• Adjust sizing: Change NODE_W and NODE_H constants

TROUBLESHOOTING
─────────────────────────────────────────────────────────────────────────
Node doesn't appear
  → Check Python syntax: python -m py_compile nodes.py
  → Restart ComfyUI server
  → Clear browser cache

Colors not right
  → Clear browser cache (Ctrl+Shift+Delete)
  → Verify config.json has correct hex values
  → Check CSS variables in DevTools

Workflow errors
  → Verify all node types exist: grep '"type"' *.json
  → Check node connections in "links" array
  → Ensure IDs are integers, not strings

Generation fails
  → Check ComfyUI logs for workflow errors
  → Verify GPU has sufficient VRAM (24GB+ recommended)
  → Confirm Minimax H3 models are installed
